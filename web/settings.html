Ключи шифруются (AES-256-GCM) и хранятся только на этом компьютере в data/config/; фронтенду отдаётся только маска. Приложение не торгует — создавайте ключ только для чтения, без прав на торговлю и вывод средств. Кнопка «ПРОВЕРИТЬ» делает один подписанный запрос к бирже и показывает статус ключа.
