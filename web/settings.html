PRIVATE API KEYS

EXCHANGEKEYSAVEDCHECK
Keys are encrypted (AES-256-GCM) and stored only on this computer in data/config/; the frontend only gets a mask. The app doesn't trade: create a read-only key, without trading or withdrawal permissions. The VERIFY button makes one signed request to the exchange and shows the key status.

UPDATE INTERVALS

The pattern scan always runs at the bar close of the profile's pattern TF. A 30 s request cache and the adaptive queue protect against exchange limits.

Cleanup deletes closed observations with their snapshots and resolved patterns older than the threshold; open observations, armed patterns and their data are left alone, and the engine keeps running. VACUUM moves the WAL into the database and compacts the file (the engine is paused for the operation and started again). After a big cleanup, press VACUUM to get the disk space back.
