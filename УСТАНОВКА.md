# FORMATION SCANNER — установка и запуск

Сканер паттернов на фьючерсах Binance: находит паттерны, ставит их под
скоринг (оценка 0–4), пишет сигналы в журнал со снапшотами графиков.

Гипотеза о работе технического анализа остаётся на пользователе: детектор и
правила скоринга подключаются в `src/core/detector.ts` и `src/core/scoring.ts`
(см. README). Без своей гипотезы приложение запускается, но ничего не находит.

## Что нужно

- Windows 10/11 (подойдёт и macOS/Linux — шаги те же, только без bat-файлов)
- Node.js версии 20 или новее — единственное, что нужно установить
- Доступ в интернет (публичное API Binance Futures; аккаунт и API-ключи НЕ нужны)

## Установка (простой путь)

1. Распакуйте архив в любую папку (путь может быть любым, кириллица допустима).
2. Запустите `install.bat` — он проверит наличие Node.js, при отсутствии
   установит его через winget и скачает зависимости проекта.
   Если Node.js ставился впервые — закройте окно и запустите `install.bat`
   ещё раз (Windows обновляет PATH только в новых окнах).
3. Запустите `start.bat` — поднимется сервер и откроется браузер.

## Установка (вручную)

1. Установите Node.js LTS с https://nodejs.org (кнопка «LTS», дальше «Далее-Далее»).
2. Откройте терминал в папке проекта и выполните:

   ```
   npm install
   npm start
   ```

3. Откройте в браузере http://localhost:8787

## Страницы

| Адрес | Что это |
|---|---|
| http://localhost:8787/ | Журнал сигналов: звёзды, фильтры, просмотрщик снапшотов |
| http://localhost:8787/cards.html | Наблюдения: паттерны в ожидании сигнала и наблюдения под скорингом; таблица профилей |
| http://localhost:8787/grid.html | Сетка: перебор комбинаций коэффициентов, тепловая карта оценок |
| http://localhost:8787/settings.html | Настройки: интенсивность, снапшоты, API-ключи |
| http://localhost:8787/dev.html | Статус: здоровье сервера, очередь запросов, проверка детектора на одной монете |

Движок запускается кнопкой СТАРТ в журнале (или сам, если был запущен до
перезапуска сервера).

## Данные

Всё хранится локально в папке `data/` (создаётся автоматически при первом
запуске): база SQLite `scanner.db` с формациями, сигналами и снапшотами.
Никуда наружу данные не отправляются, все запросы — только чтение публичных
котировок Binance.

## Если что-то не работает

- «node не является командой» — Node.js не установлен или окно терминала
  открыто до установки; переоткройте терминал.
- Порт 8787 занят — закройте другой процесс на этом порту или поменяйте порт
  в `src/server.ts`.
- `npm install` ругается на better-sqlite3 — обновите Node.js до актуальной
  LTS-версии (модуль ставится готовыми бинарями под свежие версии).
